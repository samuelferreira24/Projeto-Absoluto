# PONTO EXATO DE PARADA

## Antes da mudança para o novo chat

Estávamos respondendo a uma pergunta prática:

**O que do Sistema antigo/aplicativo antigo pode ser útil para o Projeto Absoluto atual?**

Em vez de simplesmente reutilizar código antigo, foi decidido investigar o patrimônio histórico.

### Sequência que foi executada

1. O repositório antigo `samuelferreira24/Sistema` foi inspecionado.
2. Foi localizado o arquivo `sistema-absoluto.zip`.
3. Foi identificado que o ZIP continha o aplicativo e materiais relacionados à criação.
4. Foi criado o Mini-Cérebro no Projeto Absoluto.
5. O Mini-Cérebro recebeu capacidade de aquisição de repositório.
6. Foi criado um fluxo de aquisição via GitHub para obter o patrimônio histórico sem alterar a fonte.
7. O ZIP foi colocado no fluxo de ingestão.
8. O estado agora é **investigar o conteúdo**, não construir o ABS.

### Próxima operação

O próximo chat deve fazer o Mini-Cérebro:

**ZIP → inventário → leitura → observação técnica da IA → evidências → descobertas → relações → comparação com ABS atual.**

Depois:

**o que permanece válido → o que deve ser recriado → o que foi superado → o que permanece desconhecido → novas pesquisas.**

Somente depois disso deve começar a definição/construção do ABS.

## O que NÃO fazer agora

- Não começar a implementar o ABS definitivo.
- Não escolher uma arquitetura final prematuramente.
- Não descartar código antigo só porque o aplicativo foi abandonado.
- Não assumir que uma implementação antiga é correta.
- Não assumir que uma hipótese antiga é arquitetura aprovada.
- Não reduzir a investigação a "copiar código".
- Não apagar histórico para simplificar.
