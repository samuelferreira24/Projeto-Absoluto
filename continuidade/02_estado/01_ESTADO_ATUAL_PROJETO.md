# ESTADO ATUAL — PROJETO ABSOLUTO

## Estado

Projeto Absoluto (ABS).

O projeto passou por uma evolução desde Sistema Absoluto. ABS foi definido como o sistema do Imperador, mas sua forma técnica não está congelada.

### Modelo conceitual atual

- Imperador = visão/vontade/direção.
- Sistema = executa a visão, incluindo pesquisa, análise, planejamento, descoberta, testes, aprendizado, correção e execução.
- Império = gera renda.
- Império reinveste no Imperador.
- O ciclo amplia a capacidade de visão, sistema e império.

Marte é apenas uma possibilidade/objetivo atual. Não é a definição permanente do ABS.

### Definição de trabalho

ABS é o sistema sob controle do Imperador, criado para realizar aquilo que ele determina, utilizando, adquirindo, combinando, criando, substituindo ou desenvolvendo os meios necessários para isso.

A forma do ABS pode mudar. Não deve ser reduzido a uma IA, AGI, aplicativo, multiagente, Android, Cérebro ou outra tecnologia específica.

### Método

PP + BN + AV:
- Primeiros Princípios
- Bola de Neve
- Avalanche

A abordagem é expandir possibilidades, decompor/questionar fundamentos e validar/controlar/otimizar/antecipar antes e durante a execução.

### Estado da construção

**Ainda não estamos construindo o ABS como arquitetura definitiva.**

Estamos fazendo a investigação necessária para decidir o que realmente precisa ser construído.
