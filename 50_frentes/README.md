# Frentes

Espaço reservado para frentes de execução que não fazem parte do núcleo ABS.

- `01_automacao/` — automação.
- `02_comercial/` — frente comercial.

As frentes são independentes do núcleo e podem evoluir conforme o planejamento dinâmico do projeto.
