# ABS Core

Implementação operacional do ABS V1.

## Função
É o núcleo executável atual do sistema: modelos, armazenamento, capacidades, orquestração, servidor local, bridge e atualização.

## Verificação
A autoridade operacional deve ser determinada pelo código, testes, CI e resultados verificáveis — não por documentos históricos.

## Regra
Mudanças aqui são mudanças de sistema. Não reorganizar arquivos deste diretório apenas por estética sem verificar imports, entrypoints, scripts e testes.
