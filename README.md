# Projeto Absoluto

## Ponto de entrada

Este repositório preserva o planejamento, o Cérebro, as especificações, as fontes históricas e o conhecimento de construção do Projeto Absoluto.

## Cérebro operacional V0.1

A primeira interface operacional real está disponível como módulo Python:

```bash
python -m cerebro diagnostico
python -m cerebro ingerir caminho/arquivo.md
python -m cerebro buscar "termo"
python -m cerebro aprender "Título" "Conteúdo"
python -m cerebro tarefa tarefa-1 "Objetivo"
python -m cerebro planejar
python -m cerebro executar caminho/arquivo.md --objetivo "Processar entrada"
```

O comando `executar` percorre o ciclo mínimo ponta a ponta: **ingestão → preservação → tarefa → planejamento → execução → resultado → aprendizado → consolidação**.

A operação utiliza os componentes já existentes em vez de criar uma memória paralela. A entrada permanece registrada no acervo e o aprendizado mantém origem, evidência e contexto.

## Regras fundamentais

1. O Projeto Absoluto é maior que IA, software, automação ou GitHub.
2. O Projeto possui os três pilares: Imperador Absoluto, Sistema Absoluto e Império Absoluto.
3. O passado informa a arquitetura, mas não determina a arquitetura.
4. Fontes históricas não são substituídas por resumos ou interpretações.
5. Conhecimento derivado deve preservar contexto e proveniência.
6. Documentos antigos permanecem quando ajudam a reconstruir a evolução.
7. Conteúdo não compreendido não deve ser apagado apenas para organizar.
8. A construção atual do Cérebro ocorre em `base-cerebro-v0.1`.
9. A `main` não deve receber alterações desta fase e o PR #2 não deve ser mesclado automaticamente.

## Organização

A estrutura atual e a classificação dos documentos estão descritas no índice profissional do Cérebro. O arquivo `Visao_Geral.md` é histórico e não deve ser usado como autoridade sobre a arquitetura atual.
