# Memória persistente de ferramentas — ABS V1

O conhecimento operacional das ferramentas agora possui uma camada própria de persistência SQLite.

Fluxo:

ferramenta → conhecimento → evidência → aprendizado → SQLite → reinício → restauração → novo planejamento

Isso evita que uma descoberta ou lição aprendida dependa da duração de um processo ou conversa.

A memória continua separada de:

- modelo de IA;
- código de uma ferramenta;
- autorização;
- conexão operacional;
- histórico bruto do Mini-Cérebro.

O Mini-Cérebro preserva o patrimônio histórico amplo. A memória operacional de ferramentas registra o conhecimento atual necessário para o ABS utilizar recursos. Os dois podem futuramente ser relacionados sem serem confundidos.
