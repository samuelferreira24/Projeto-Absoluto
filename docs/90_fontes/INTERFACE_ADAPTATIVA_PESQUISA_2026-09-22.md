# Pesquisa — Interface Adaptativa Espacial do ABS

Data: 2026-09-22

## Objetivo da pesquisa

Registrar referências reais de tecnologia e pesquisa relacionadas à direção desejada para a interface do ABS: uma interface que não seja uma tela fixa, mas um ambiente visual adaptável no qual o Imperador possa pedir diferentes formas de representação, manipular objetos, mudar ângulos, adicionar/remover elementos e alternar entre representações.

## Principais referências encontradas

### 1. Apple — visionOS / computação espacial

O visionOS trabalha com janelas, volumes e espaços imersivos. O conteúdo 3D pode ser organizado em profundidade e manipulado. No visionOS 26, a Apple ampliou recursos volumétricos, rotação 3D, manipulação de objetos, movimento/escala e integração entre SwiftUI, RealityKit e ARKit.

A direção confirma a viabilidade técnica de:
- objetos 3D manipuláveis;
- mudança de posição, rotação e escala;
- cenas com profundidade;
- diferentes formas de apresentar conteúdo;
- conteúdo que pode ser reposicionado no espaço;
- integração entre interface 2D e conteúdo 3D.

Fontes:
- https://developer.apple.com/documentation/visionos
- https://developer.apple.com/videos/play/wwdc2025/317/
- https://developer.apple.com/videos/play/wwdc2025/290/
- https://developer.apple.com/wwdc26/guides/visionos/

### 2. MorphGUI — interface modificável por linguagem natural

Pesquisa publicada no International Journal of Human-Computer Studies em 2026. O MorphGUI explora personalização de interfaces por linguagem natural, permitindo solicitar alterações funcionais e visuais e traduzir essas solicitações em modificações ou novos componentes.

Isso é diretamente relevante para a ideia:
> "Mostre em modo de botões."
> "Mude a disposição."
> "Coloque isso ao lado."
> "Mostre somente esta parte."

Fonte:
- https://www.sciencedirect.com/science/article/pii/S1071581925002502

### 3. MIT Media Lab — linguagem para manipulação de cenas 3D

O projeto "Visually-Grounded Language Understanding for the Interface of an Interactive Design System" demonstra uso de linguagem falada para selecionar e manipular objetos em cenas 3D.

Isso comprova uma linha de pesquisa compatível com:
- selecionar objetos por linguagem;
- manipular objetos espacialmente;
- usar linguagem como camada de interação com uma cena.

Fonte:
- https://www.media.mit.edu/projects/visually-grounded-language-understanding-for-the-interface-of-an-interactive-design-system/overview/

### 4. Google DeepMind — Project Astra

O Project Astra pesquisa interação multimodal com visão, memória, contexto, objetos e ferramentas. A página atual descreve compreensão de objetos, interação por tela/câmera, memória multimodal, uso de ferramentas e assistência entre dispositivos.

É uma referência para a futura camada:
> linguagem + visão + memória + contexto + ação.

Fonte:
- https://deepmind.google/models/project-astra/

## Conclusão da pesquisa

As peças fundamentais da ideia já existem ou estão em pesquisa avançada:
1. computação espacial;
2. objetos 3D manipuláveis;
3. linguagem natural aplicada à interface;
4. compreensão visual;
5. memória multimodal;
6. interfaces adaptáveis.

A proposta do ABS, porém, combina essas linhas de maneira própria: a interface não deve ser o formato fixo do sistema. Ela deve ser uma camada adaptativa para visualizar e comandar o ABS.

A pesquisa não deve ser tratada como prova de que existe hoje um produto pronto igual ao ABS. Ela serve como referência técnica e conceitual.
