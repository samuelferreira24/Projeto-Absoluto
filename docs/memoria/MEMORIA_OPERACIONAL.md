# Memória Operacional — Projeto Absoluto

## Princípios
1. GitHub guarda a memória técnica versionada e evidências permanentes.
2. O operador 24/7 mantém estado operacional vivo na VPS.
3. ChatGPT não é a única memória nem o único operador.
4. ABS permanece autoridade/orquestração/verificação; OpenClaw é operador/inteligência operacional provisória.
5. Mudanças importantes devem produzir evidência e, quando apropriado, ser consolidadas no Git.

## OpenClaw
O OpenClaw deve observar, diagnosticar, executar manutenção autorizada, registrar mudanças e escalar incertezas. Não deve assumir autoridade arquitetural do ABS.

## Memória futura
A camada operacional poderá evoluir de arquivos Markdown → banco operacional → memória consultável pelo ABS/OpenClaw, sem abandonar o Git como histórico versionado.
