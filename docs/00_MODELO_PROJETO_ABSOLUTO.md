# MODELO DO PROJETO ABSOLUTO

## 1. Definição

O Projeto Absoluto é o projeto maior: a visão, o método, os princípios, os objetivos e a direção que o Imperador pretende transformar em realidade.

O Projeto Absoluto não é sinônimo de aplicativo, sistema, IA, repositório ou ABS.

A implementação completa ainda está em descoberta e construção. O Imperador possui a visão e está aprendendo a transformar essa visão em execução enquanto constrói.

## 2. Relação entre visão, sistema e projetos

```
PROJETO ABSOLUTO
│
├── VISÃO / MÉTODO / PRINCÍPIOS / OBJETIVOS
│
├── SISTEMA
│   └── infraestrutura de capacidade para ajudar o Imperador
│       a pesquisar, aprender, planejar, construir, testar e executar
│
├── PROJETOS
│   ├── ABS ← primeiro projeto em construção
│   ├── futuros projetos
│   └── projetos ainda não definidos
│
├── IMPÉRIO
│   └── capacidade econômica/operacional produzida pelos projetos
│
└── HISTÓRICO / CONHECIMENTO
```

Essa representação é conceitual. Ela não exige que cada camada tenha um repositório separado.

## 3. ABS

O ABS é o primeiro projeto que o Imperador está tentando construir dentro do Projeto Absoluto.

ABS não representa todo o Projeto Absoluto.

ABS V1 é o segundo protótipo do ABS e deve ser tratado como uma versão do primeiro projeto, não como a definição permanente do ABS.

O ABS poderá evoluir para V2, V3 e versões posteriores. A arquitetura deve permanecer aberta para substituição, expansão ou abandono de componentes.

## 4. Sistema

O Sistema existe porque o Imperador não parte de uma capacidade técnica completa para executar a visão.

Ele é construído para aumentar essa capacidade.

Sua função é ajudar a:
- pesquisar;
- aprender;
- descobrir ferramentas;
- planejar;
- construir;
- executar;
- testar;
- registrar resultados;
- preservar continuidade;
- aprender com os resultados;
- aumentar a capacidade de realizar projetos futuros.

O Sistema é meio de execução e ampliação de capacidade, não o objetivo superior do Projeto Absoluto.

## 5. Aprender enquanto constrói

O Projeto Absoluto não pressupõe que o Imperador saiba antecipadamente como implementar tudo.

O processo real é evolutivo:

```
VISÃO → necessidade → pesquisa → aprendizagem → hipótese → experimento
→ construção → teste → resultado → conhecimento → capacidade
→ nova visão/novo objetivo → novo ciclo
```

IAs são ferramentas de aprendizagem, pesquisa e construção dentro desse processo.

Uma recomendação de uma IA não vira automaticamente decisão do Projeto.

## 6. Autoridade

A autoridade sobre visão, princípios, direção e decisões do Projeto pertence ao Imperador.

O Sistema e as IAs podem pesquisar, analisar, propor, implementar quando autorizados, testar, registrar evidências e identificar problemas.

Eles não devem alterar silenciosamente a visão, princípios ou decisões do Imperador.

## 7. Repositórios

A hierarquia conceitual não depende da quantidade de repositórios.

É permitido que, em determinado estágio, vários projetos compartilhem um repositório, um sistema tenha um repositório próprio, ABS e Sistema estejam no mesmo repositório ou componentes sejam separados futuramente.

A organização física deve seguir necessidade operacional e continuidade, e não redefinir o significado conceitual do Projeto Absoluto.

## 8. Regra para novos projetos

Quando surgir um novo projeto, registrar pelo menos:
- identidade;
- objetivo;
- relação com o Projeto Absoluto;
- estado atual;
- dependências;
- recursos;
- sistema/capacidades utilizados;
- evidências;
- decisões;
- próximo ponto de execução.

Um projeto pode reutilizar o Sistema/ABS ou criar capacidades próprias quando isso for necessário.

## 9. Não confundir

- Projeto Absoluto ≠ Sistema.
- Projeto Absoluto ≠ ABS.
- Sistema ≠ ABS.
- ABS ≠ IA.
- ABS V1 ≠ ABS definitivo.
- visão ≠ implementação.
- ideia ≠ hipótese validada.
- hipótese ≠ capacidade operacional.
- repositório ≠ projeto.
- documentação ≠ prova de funcionamento.

## 10. Princípio de evolução

O Projeto Absoluto deve poder crescer sem precisar conhecer hoje sua forma final.

Construir capacidade agora deve aumentar a capacidade de descobrir, construir e realizar coisas maiores depois.

Este documento é uma definição arquitetural de alto nível. Detalhes técnicos do Sistema e do ABS pertencem às suas respectivas fontes.
