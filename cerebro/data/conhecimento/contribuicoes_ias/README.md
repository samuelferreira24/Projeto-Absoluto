# Contribuições de IAs

Área reservada para registrar entendimentos produzidos por diferentes IAs, contas e chats sobre o Projeto Absoluto.

## Objetivo

Preservar contribuições independentes com rastreabilidade de origem, permitindo comparação, convergência, divergência, revisão e evolução.

## Estrutura

- INDICE_CONTRIBUICOES_IA.jsonl — índice leve das contribuições.
- Cada contribuição futura deve ter seu próprio registro/arquivo, com origem identificada.
- O procedimento geral está em cerebro/especificacao/PROCEDIMENTO_REGISTRO_ENTENDIMENTOS_IA_V1.md.

## Regra central

Não misturar contribuições de contas/chats diferentes. Cada contribuição mantém sua identidade, origem, contexto e proveniência.

Se um identificador real de conta ou chat não estiver disponível, registrar não_disponível; nunca inventar.
