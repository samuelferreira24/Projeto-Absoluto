# Subquadro — Níveis de controle do Android — V1

| Nível | O que o Sistema consegue controlar | V1 |
| --- | --- | :---: |
| **0 — Execução** | O Sistema simplesmente roda dentro do Android, como um aplicativo/processo | 🟢 |
| **1 — Recursos próprios** | Arquivos, armazenamento, rede, processos e recursos aos quais o Sistema tem acesso | 🟢 |
| **2 — Aplicativos** | Abrir, utilizar e coordenar aplicativos; automatizar ações quando houver mecanismos disponíveis | 🟢/🟡 |
| **3 — Interface do Android** | Interagir amplamente com a interface: tocar, clicar, escrever, navegar, observar telas etc. | 🟡 |
| **4 — Serviços e APIs do sistema** | Utilizar e controlar serviços Android expostos por APIs e permissões | 🟡 |
| **5 — Privilégios avançados** | Acesso por mecanismos como ADB, permissões especiais e outros recursos privilegiados | 🟡 |
| **6 — Root** | Acesso administrativo muito mais profundo ao dispositivo | 🟡 |
| **7 — Sistema operacional** | Modificar/controlar componentes do próprio Android | 🟡 |
| **8 — Android próprio/adaptado** | Construir uma versão do Android/AOSP adaptada para o Sistema | 🟡 |
| **9 — Controle integral** | Sistema com domínio operacional máximo possível sobre o Android e seus recursos | 🟡 — objetivo a investigar |

## Registro
Este subquadro registra a escala de níveis de controle investigada para **Hardware → Android**. O nível 9 é um objetivo de investigação, não uma afirmação de que já foi alcançado. Os níveis 🟡 permanecem abertos para investigação futura.
