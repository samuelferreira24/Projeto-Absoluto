# Estado do Cérebro

Esta área registra **estado observado e snapshots do Cérebro**.

## Função
- estado observado;
- snapshots temporais;
- situação de ligação/continuidade;
- registros de estado que precisam ser preservados como evidência histórica.

## Autoridade
Para saber o estado operacional atual do Projeto/ABS, não usar um snapshot isolado como fonte principal.

Consultar:
1. código atual;
2. testes/CI;
3. evidências operacionais;
4. Project Knowledge em `continuidade/07_conhecimento/project_knowledge.json`;
5. documentação operacional;
6. snapshots desta área.

## Conteúdo atual
- `STATUS_ABS_V1_2026-09-22.md` — snapshot consolidado do estado da V1 naquela data.
- `STATUS_CEREBRO_LIGADO.md` — registro de estado/ligação do Cérebro.

## Regra
Estado é uma fotografia verificável de uma situação, não uma especificação de arquitetura.

Snapshots antigos permanecem preservados e devem ser identificados pela data/versão. Se contradisserem o estado vivo posterior, são históricos, não estado atual.
